# Report size and progressive disclosure

## Reader levels
1. Executive summary
2. Functional/business view
3. Technical view
4. Evidence appendices and separate exports

## Rules
- Executive summary: target 1-2 pages.
- Main report: critical capabilities, processes, entities, configuration, findings, and decisions.
- Move large inventories, full coverage registry, evidence ledger, graph export, handoffs, and field mappings to appendices/artifacts.
- Keep source excerpts short and necessary.
- Split oversized diagrams into overview and focused diagrams.
- Link to full exports instead of embedding large YAML/JSON blocks.

Report size is governed by relevance, not a fixed page count. Do not omit critical evidence solely to shorten the document.
